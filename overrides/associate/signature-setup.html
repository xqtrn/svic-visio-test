Email signature

Your email signature

Every message you send on behalf of Silicon Valley Investclub carries the same signature: your name, your title, the logo and the confidentiality notice. Generate yours below, then follow the nineteen steps to install it in Mail on your Mac.

Mail on macOS will not draw a picture that lives on a website — after a restart it still shows a question mark even when the file is otherwise correct. The Mail file we give you contains the logo, so the picture is still there after a reboot. The file has to be written into your Library and locked, or Mail overwrites it. Allow about ten minutes, once.

1 · Generate your signature

Download Mail file is the one you need for step 14 — it is a .mailsignature that already contains the company logo, so Mail still shows it after a restart. Copy HTML code and Download HTML file are the HTTPS markup for Outlook and Gmail on the web. Copy signature copies it as formatted text, for clients that accept a paste.

2 · Put it into Mail on your Mac

Before you start: have your signature generated above, quit Mail completely rather than minimising it, and know your Mac password — the Library is a system folder. TextEdit is already installed on every Mac.

Phase 1

Create a placeholder signature

1

Open the Apple Mail settings

Launch Mail, click the Mail menu in the bar at the top of the screen and choose Settings… — on older versions of macOS it is called Preferences….

Keyboard: ⌘ , opens it from anywhere in Mail.

The Mail menu. Settings sits below About Mail.
2

Navigate to the Signatures tab

Open the Signatures tab, then click the + button to create a new signature.

The Signatures tab. The + button is under the middle column.
3

Configure a placeholder signature

  • Name your signature — for example SVIC.
  • Type temporary placeholder text into the box on the right — for example PLACEHOLDER.

The real signature does not go in here. This step only makes Mail create the file you are going to replace.

A named signature with placeholder text in the editing box.
4

Apply your signature

Drag your signature onto the email account you want it on in the left column, and set it as the default under the Choose Signature dropdown at the bottom.

The signature dragged onto the account, and selected under Choose Signature.
5

Save and exit Apple Mail

Close the Settings window and quit Mail completely with ⌘ Q. This action saves your signature file to the system library.

Quitting matters — closing the window is not enough. Mail writes the file on quit, and it will overwrite your work later if it is still running.

Phase 2

Locate the signature file

6

Access the Mail library

Open Finder, then click Go in the menu bar and choose Go to Folder.

Finder → Go → Go to Folder.
7

Navigate to the signatures folder

Type ~/Library/Mail and click the Go button.

The Go to Folder box with ~/Library/Mail typed in.
8

Locate the latest version folder

Open the folder starting with V followed by the highest number — for example V10, V11.

Several V folders; open the one with the highest number.
9

Enter the MailData folder

Inside it, open MailData.

The MailData folder.
10

Open the Signatures folder

Inside MailData, open Signatures.

The Signatures folder inside MailData.
11

Identify your signature file

Sort by Date Modified to bring the newest files to the top, and look for the file ending in .mailsignature.

If you have made signatures before, there will be several. The one you want is the one you just created — the newest.

Files sorted by Date Modified; the newest .mailsignature is yours.
Phase 3

Replace it with your HTML

12

Edit the signature file

Right-click the .mailsignature file and choose Open With → TextEdit.

Open With → TextEdit on the .mailsignature file.
13

Open the Mail file you downloaded

Press Download Mail file in step 1, then open that .mailsignature in TextEdit beside the placeholder file from step 12.

Do not use Copy HTML code here — that markup is a website link, and Mail draws a question mark for it after a restart.

The downloaded Mail file open beside the placeholder .mailsignature.
14

Keep the Message-Id, replace the rest

In the placeholder file, copy the Message-Id: line. Select everything in that file, paste the downloaded Mail file, then put the copied Message-Id: line back — directly under the Content-Type block, before Mime-Version.

Critical: the Message-Id line is how Mail identifies the file — lose it and the signature disappears. The downloaded file already contains the logo; do not paste the HTML-only copy in its place.
Placeholder open, ready to keep Message-Id and replace the rest with the Mail file.
15

Confirm changes

The file should start with Content-Type: multipart/related, still carry your Message-Id, and include a block named logo.png after the HTML.

The .mailsignature file with Message-Id kept and the Mail file in place.
16

Save the file

Use ⌘ S to save.

Saving the file in TextEdit.
17

Lock the file

Right-click your signature file and choose Get Info.

Get Info on the .mailsignature file.
18

Check the Locked checkbox

Tick Locked. This prevents Mail from overwriting your HTML.

The Locked checkbox in the Get Info window.
19

Verify results

Open Mail and go back to Settings → Signatures to check that the signature looks the way you want.

Then send one message to yourself and look at it as the recipient does — that is the real test.

The finished signature shown in the Signatures pane.

3 · If something looks wrong

The signature reverted to “PLACEHOLDER” after I reopened Mail

The file was not locked, so Mail rewrote it from its own copy. Repeat steps 12 to 18 and do not skip Locked in Get Info. Mail has to be quit while you edit the file.

The logo is missing or everything came out grey

In Settings → Signatures, under the editing box, there is a checkbox reading Always match my default message font. If it is ticked, Mail strips the formatting and the image. Untick it, then repeat the file replacement.

A question mark sits where the company logo should be

Mail will not draw a picture that lives on a website — a restart does not fetch it either. Install the Mail file from this page (it contains the logo). After that, new messages show the picture without loading remote content. On iPhone: Copy signature, then Settings → Mail → Signature, and paste.

The signature does not appear on new messages

It was created under All Signatures rather than on your account. Drag it onto your address in the left column and select it under Choose Signature — that is step 4.

I have several .mailsignature files and cannot tell which is mine

Sort the folder by Date Modified. The one you created last is at the top. If you are still unsure, open them in TextEdit — the placeholder text you typed in step 3 is inside the right one.

Can I use my own font?

Mail renders only web-safe fonts in signatures — Arial, Helvetica, Times New Roman, Georgia, Verdana. Anything else falls back to a system font on the recipient's machine. Our block already uses web-safe fonts, so leave them as generated.

The logo arrives as an attachment instead of appearing in the message

That happens when an image is pasted as a file rather than taken from this page. Use Download Mail file for Mac, or the HTML copy for Outlook and Gmail. Do not drag a PNG into the Signatures box.

It looks different for some recipients

Every client renders HTML its own way. The block is built with table layout, inline styles and absolute image links, which is as consistent as email gets. Send yourself a test to a Gmail address and to an Outlook address before you decide something is broken.

I need a signature on a second account

Repeat the whole procedure for that account: a placeholder of its own in step 3, dragged onto that address in step 4, and its own .mailsignature file replaced. Each account holds its own.

It appears twice

You also typed one into the message body, or a draft already carried one. Keep only the one Mail adds.
